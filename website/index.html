04 THE DETAILS

Good to
know.

A few quick answers before you head out.

What is TurboCraft Launcher?

TurboCraft is an open-source Android launcher for Minecraft: Java Edition, with support for customization, different game versions and mod loaders.

Which devices can run it?

TurboCraft requires Android 8.0 or newer. Performance and game compatibility depend on your device, selected version, renderer and mods.

Which APK should I download?

The universal APK is the easiest choice if you are unsure. The arm64-v8a build is intended for most modern 64-bit ARM Android devices. Other builds are available for supported architectures.

Do I need Minecraft: Java Edition?

TurboCraft is a launcher, not a copy of the game. To use official online services, sign in with a Microsoft account that owns Minecraft: Java Edition.

Where can I get help?

Join the Discord community for help and discussion, or report a reproducible issue on GitHub.
